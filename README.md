# Java Game
Utilizing Java to create a simple dungeon crawler game....currently a work in progress.

### Future Functionalities

* An interactive UI (most likely to be implemented using Java Swing)
* Simple pixel art for sprites and backgrounds
* A game loop with real time updates and a pause/play function
